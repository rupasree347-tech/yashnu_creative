# Yashnu Creative

Yashnu Creative is a creative design agency website built with Python Flask.

## Services

- Graphic Design
- Social Media Management
- Digital Marketing
- Creative Ads
- Website Design
- Healthcare Marketing
- Business Branding

## Run Locally

1. Install Python.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Create a `.env` file using `.env.example` and add your email configuration.
4. Start the application:

   `python app.py`

5. Open the local URL displayed in the terminal.

## Security

Do not upload `.env`, passwords, or other secret credentials to GitHub.
